# SEBA BAND

Web pre rómsku live kapelu — SvelteKit, TypeScript, Tailwind CSS.

## Spustenie

```bash
cd seba-band
npm install
npm run dev
```

Otvorte [http://localhost:5173](http://localhost:5173).

## Produkčný build

```bash
npm run build
npm run preview
```

## Obsah, ktorý treba aktualizovať

- Obsadené termíny: `src/lib/data/bookings.ts`
- Recenzie, videá, galéria: `src/lib/data/`
- Kontakt: `src/lib/data/site.ts`

Fotografie sú v `static/images/`.
